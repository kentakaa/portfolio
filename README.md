# Arshad — Software Developer Portfolio

A modern, responsive personal portfolio website showcasing my work, technical skills, education, projects, and experience as a software developer.

## Overview

This portfolio is designed to present my development journey and projects in a clean, interactive, and modern interface.

The website focuses on:

* Software development projects
* Backend development
* Java & Spring ecosystem
* Web development
* Databases
* Technical skills and experience
* Education and certifications

## Features

* Modern responsive UI
* Responsive navigation
* Smooth scrolling
* Scroll-based animations and transitions
* Interactive project showcases
* Skills categorized by technology
* Resume viewing and download
* GitHub and LinkedIn integration
* Mobile-friendly design
* Accessibility considerations
* Reduced-motion support

## Tech Stack

* HTML5
* CSS3
* JavaScript
* GSAP / ScrollTrigger
* Lenis
* Git & GitHub

## Running Locally

Clone the repository:

```bash
git clone https://github.com/kentakaa/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Open `index.html` in a browser, or use a local development server such as VS Code Live Server.

## Deployment

The project is a static website and can be deployed using platforms such as:

* GitHub Pages
* Netlify
* Vercel

Pushes to the connected repository can be used to trigger automatic deployments depending on the hosting configuration.
